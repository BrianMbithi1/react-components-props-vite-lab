# Personal Blog (React)

## Components
- App: root; children Header, About, ArticleList
- Header: h1 with `name` prop
- About: logo (`image`, alt "blog logo") and `about` text
- ArticleList: maps `posts` to Article (unique `key`)
- Article: `title`, `date`, `preview`

## Run
npm install
npm start
npm test
